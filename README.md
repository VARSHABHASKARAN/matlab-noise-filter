# 🎧 MATLAB Noise Removal Project

This project simulates the removal of noise from an audio signal using a **Butterworth low-pass filter** in MATLAB.

## 📁 Files Included

| File | Description |
|------|-------------|
| `main.m` | Main script that reads, filters, plays, and saves the audio |
| `generate_audio.m` | Script to generate synthetic noisy audio using sine wave + white noise |
| `noisy_audio.wav` | Sample input audio with noise |
| `cleaned_audio.wav` | Output after filtering (can be generated again) |

## 🔧 Features

- Low-pass filter design
- Time domain and spectrogram visualization
- SNR (Signal-to-Noise Ratio) calculation
- MATLAB sound playback and file saving
